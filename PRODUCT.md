# Product

## Register

product

## Platform

web

## Users

The primary user is an individual manager organizing their own business and management workload. They use the product for both quick daily prioritization and more deliberate weekly planning, with the matrix serving as their daily command center.

## Product Purpose

Eisenhower Matrix turns a lightweight task list into a clear action plan organized by urgency and importance. Tasks contain a title, urgency and importance choices, a derived quadrant, and completion status. Work persists in browser local storage; the first version has no accounts, cloud backend, collaboration, or delegation workflow. It ships as a static GitHub Pages app built with vanilla HTML, CSS, and JavaScript. Success means a manager can turn an unruly workload into a confident “do next” plan in under a minute.

## Positioning

The fastest, clearest way for an individual manager to turn competing responsibilities into an actionable daily and weekly plan.

## Brand Personality

Focused, confident, and quietly playful. The product should feel professional without becoming corporate or sterile, and engaging without becoming whimsical.

## Anti-references

Avoid busy enterprise dashboards, cartoonish or whimsical gamification, conspicuous AI-generated interface patterns, and generic beige “calm productivity” styling. The interface should not make a lightweight workflow feel complex.

## Design Principles

- Make priority visible and the next action immediately clear.
- Keep capture and classification lightweight.
- Support fast daily action and thoughtful weekly planning with the same core model.
- Reward useful behavior with purposeful feedback and motion, never distraction.
- Make local persistence feel dependable, private, and understandable.

## Accessibility & Inclusion

Target WCAG AA with complete keyboard support, visible focus states, quadrant cues that do not rely on color alone, and a reduced-motion mode that preserves clear interaction feedback.
